### 🛠️ Repository Overview
This repository automatically builds and publishes my CV using GitHub Actions:
- **`Shihwei_Lin_CV.tex`**: Master LaTeX source code.
- **`scripts/generate_page.py`**: Python script that parses the `.tex` source and updates the web template.
- **`templates/cv_template.html`**: Clean, responsive HTML/CSS template for GitHub Pages.
- **`.github/workflows/compile-and-release.yml`**: CI/CD pipeline that compiles the PDF, creates a GitHub Release, and deploys the web version to GitHub Pages.
